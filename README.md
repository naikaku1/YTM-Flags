# YTM Flags

YouTube Music の試験スイッチ(実験フラグ)を、自分のブラウザの中だけで切り替える Chrome 拡張です。

YouTube Music は、新しいデザインや機能を一部の人にだけ先に配ることがあります(2026 年 9 月からの新しいプレイヤーバーなど)。配られるかどうかは YouTube 側が決めていて、設定画面からは選べません。この拡張を使うと、次のことができます。

- **新しいデザインが来た人が、元のデザインに戻す**
- **まだ来ていない人が、新しいデザインを先に試す**
- **YTM の JS に入っているのに、まだ誰にも配られていない機能を探して試す**

> **非公式の拡張です。** YouTube・Google とは関係ありません。YouTube Music の作りが変わると、知らないうちに効かなくなることがあります。

## 入れ方

1. このリポジトリをダウンロードして展開する(緑の **Code** → **Download ZIP**)
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにする
3. **パッケージ化されていない拡張機能を読み込む** を押し、展開したフォルダ(`manifest.json` が入っているフォルダ)を選ぶ

Chrome 111 以降が必要です。Edge などほかの Chromium 系ブラウザでも同じ手順で入るはずですが、試したのは Chrome だけです。

更新する時は、新しい版で展開したフォルダを置き換えてから、`chrome://extensions` でこの拡張の更新ボタン(↻)を押してください。

## 使い方

1. YouTube Music のタブで、ツールバーの拡張アイコンを押す
2. 切り替えたいスイッチの **ON / OFF** を選ぶ
3. **再読み込み** を押す

| 選択 | 意味 |
| --- | --- |
| 既定 | YouTube から届いた設定のまま |
| ON | その機能を使う |
| OFF | その機能を使わない |

- 各スイッチの下に、YouTube から届いた元の値(「サーバー: …」)が出ます。`true` なら、あなたにはもう配られています。「なし」ならまだです
- 上書きしている数がアイコンに出ます。やめる時は **すべて既定に戻す** を押して再読み込みしてください

ポップアップには 4 つの欄があります。

| 欄 | 中身 |
| --- | --- |
| よく使う | 新プレイヤーバーと、コードから見つけた機能(下の表) |
| 上書き中 | いま上書きしているスイッチ |
| すべてのスイッチ | YouTube から届いている全部のスイッチ。名前で検索して切り替えられる |
| 届いていないスイッチ | **JS から探す** を押すと、YTM の JS に書かれているのに届いていないスイッチが一覧で出る |

## 届いていないスイッチを探す仕組み

YTM のページは、本体の JS の中でスイッチを `F("スイッチの名前")` のような形で確かめています(`F` の部分は YTM の更新のたびに変わります)。**JS から探す** を押すと、次のことをします。

1. 開いている YTM のタブが読み込んでいる本体の JS を読む
2. その中で「届いたスイッチの名前を一番多く読んでいる関数」を、スイッチを読む関数とみなす
3. その関数が読む名前から、このアカウントに届いている名前と、ログアウト状態のトップページに届いている名前を除く

残った名前は、**まだ誰にも配られていない機能・A/B テストで自分に来ていない機能・終わった実験** のどれかです。ブラウザからは見分けがつきません。名前から見て不具合の修正・停止用・記録用らしいものは最初は隠していて、**修正・記録用なども出す** で全部出せます。

結果は拡張に保存されます。YTM が更新されると探し直すよう表示が出ます。

### コードから見つけた機能(2026 年 10 月時点)

**よく使う** に入れてあります。✓ 以外はコードから読み取った中身で、ON にして効くかどうかは確かめていません。

| スイッチ | 中身 |
| --- | --- |
| `music_web_enable_album_art_zoom` | ✓ アルバム・プレイリストのジャケットをクリックすると、高解像度の画像が全画面で開く |
| `music_web_enable_equalizer_now_playing_indicator` | 再生中の曲の印を、スピーカーから動くイコライザーにする |
| `music_home_enable_new_content_pill` | タブに戻った時にホームのおすすめが古くなっていたら、「新しいおすすめ」ボタンを出す |
| `music_web_enable_library_page_scroll_persistence` | ライブラリに戻った時、スクロール位置を保つ |
| `music_populate_web_player_bar_using_queue_metadata` | プレイヤーバーの高評価ボタンを、キューの曲情報から作る |
| `enable_equal_shelf_spacing` | 横に流れる棚の間隔をそろえる |
| `music_web_enable_diwali_india_promo_interactions` | 高評価・再生ボタンでディワリの花火が出る(インド向けの季節の販促) |
| `music_web_enable_contained_content_layout` | ページ全体ではなく中身だけがスクロールする配置(新プレイヤーバーの欄に入れてあります) |

## できないこと

この拡張が変えるのは、ページが「どう表示するか」を判断するスイッチだけです。YouTube から届くデータは変えません。そのため次の制限があります。

- **サーバーの協力が必要な機能は動きません。** ボタンや画面が出ても、中身が空だったり、操作が断られたりします(AI 検索など)
- **JS にコードが入っていない機能は出せません。** 開発中でまだ配られていないコードは、どのスイッチを入れても動きません
- **プレイヤーバーの高評価・低評価ボタンが出ません**(新プレイヤーバーを新旧どちらに切り替えた場合も)。高評価のデータは YouTube がその人に配られたデザインの形で送ってくるため、切り替えた側のバーでは読めません
- それ以外のプレイヤーバーの操作(再生・一時停止・シーク・前後の曲・ミュート・リピート・シャッフル・プレイヤーページの開閉・キーボードの `;`)は、新旧どちら向きに切り替えても使えることを確認しています(ログアウト状態の Chrome で確認。ログイン中も切り替え自体は効きます)
- 名前に `killswitch` が付くものは、ON にすると何かが **止まる** スイッチです

## 受け付けない名前

- `force_` で始まる名前は追加できません。YTM はこの名前のスイッチを「社内用の実験スイッチ」として YouTube のサーバーに送ってしまうためです。この拡張は、自分のブラウザの表示を変える範囲だけで使うものにしています
- `__proto__` など、入れ物そのものを書き換えてしまう名前も受け付けません

## 仕組み

- `inject.js`: ページのスクリプトより先に走り、YouTube Music の設定(`ytcfg` の `EXPERIMENT_FLAGS`)が入った直後に上書きします。上書きが無い時は何もしません
- `bridge.js`: 拡張に保存した上書きを、ページの localStorage(`ytmFlagsDev.overrides`)に写します。食い違っていたら(初めて開いた時・サイトデータを消した後など)、1 回だけ自動で読み込み直します
- `popup.*`: 切り替え画面。YouTube から届いた元の値は、上書きしている間だけページに置く `window.__ytmFlagsDev` から読みます

拡張が自分から通信するのは、**JS から探す** を押した時だけです。その時は、YouTube Music 自身の本体の JS と、ログアウト状態のトップページを読みに行きます。それ以外の通信の書き換えや、外部への送信は一切しません。
